# Costume check: second pass (10 Nov 2026)

A second look at `data/costume-availability.json`, mainly for costumes that came back later. I checked all 45 that weren’t “yes”, all 22 “event” yeses, and spot-checked the riskiest “local” yeses: 94 costumes in all. One entry per costume is in `data/costume-availability-check.json`. The main file isn’t changed.

## Changes

**No → yes (marked “never released” but they were released):**

- `3-copy-2019`, `6-copy-2019`, `9-copy-2019` · Venusaur, Charizard, Blastoise · Clone · no → **yes, local**. Four-star raids worldwide, Pokémon Day 2020 (25 Feb – 2 Mar 2020).
- `25-copy-2019` · Pikachu · Clone · no → **yes, local**. GO Snapshot photobomb, same event.
- `25-feb-2019` · Pikachu · Feb 2019 · no → **yes, local**. This is the 2019 detective-hat Pikachu: snapshot photobombs worldwide 7–17 May 2019, and wild 11–12 Aug 2019. It has no shiny, so Leek Duck never named it.
- `26-feb-2019` · Raichu · Feb 2019 · no → **yes, local**. Detective-hat Raichu, by evolving that 2019 Pikachu (Serebii lists it in the event).
- `282-gofest-2021-noevolve`, `330-gofest-2021-noevolve` · Gardevoir, Flygon · GO Fest 2021 · no → **yes, event, but only one of the two**. Meloetta hats, from GO Fest 2021’s ticket Special Research, where you picked Gardevoir *or* Flygon.

**Yes → unsure:**

- `25-doctor` · Pikachu · Doctor (Pikachu, Ph.D.) · yes → **unsure**. Its only source is the Platinum PokéStop Showcase medal, which needs 100 first-place Showcase wins.

**Group only (still yes; suggestions):** these were free for everyone worldwide, so they fit “local” better than “event”:

- the nine Pikachu Visor starters (GO Fest 2026: Global, free)

**Wording fixes (verdict unchanged):**

- `68-wildarea-2026-01` Machamp, Modern Jacket: it is *not* in the Into the Wild GO Pass. It only comes from three-star raids at GO Wild Area 2026: Global, 14–15 Nov.
- `999-coin-a1` Gimmighoul (9): Golden Lures did *not* attract it. It came from the free Timed Research, the 9,999-Stardust Field Research or a Coin Bag.
- `133-may-2023` Eevee “May 2023” is the explorer-hat Eevee itself. Leek Duck calls it “Safari Hat”, shiny since 7 Oct 2023. The import missed its name and shiny date because the game spells the code `May_2023`. It is still a no: City Safari only, plus the Boston 2026 re-run for ticket holders.
