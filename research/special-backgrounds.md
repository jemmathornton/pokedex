## Main uncertainties

- **Matched by picture only:** `sb_MidAutumn` (Moonlight 2026), `sb_WorldSpecial_Blue` (Worlds 2026 Tinkaton) and `sb_GoFest2025_Eternatus` (Dark Skies / Max Finale): no source names these files, but each is the plain base layer of the matching picture on Serebii.
- **Dark Skies list:** Serebii names 23 more species than Dittobase; only those both list are in the main list (the rest are in the JSON’s `unsure`).
- **Seasonal lists:** Dittobase adds GO Pass legendaries (Moltres; Terrakion, Virizion) and Pikipek that Serebii leaves out.
- **Mega background reused:** that Mega Ascension and the Mega Finale (Sep 2026) gave the same picture as GO Tour Kalos’s Mega one is from Dittobase only.
- **Team Leader backgrounds:** Triumph Together dates differ (Dittobase July, Leek Duck August 2024).
- **GO Wild Area 2026** is half upcoming (the weekend is 14–15 Nov) and has no picture file yet; Crowned or Hero Zacian/Zamazenta differs between Leek Duck and Dittobase.
- **Shiny:** where a source doesn’t say, the JSON says “not stated”.
